## 开启 windows 功能

1. 打开 hyper-V 平台功能

   ![alt text](/assets/img/2025-03-12-wsl2-gpu-gui/image.png)

2. 打开 Linux 子系统功能

   ![alt text](/assets/img/2025-03-12-wsl2-gpu-gui/image-1.png)

3. 重启系统以生效

## 安装 wsl 2

1. 下载 [wsl 2 核心包](https://learn.microsoft.com/en-us/windows/wsl/install-manual#step-4---download-the-linux-kernel-update-package)并安装
2. 下载 [Linux 发行版](https://learn.microsoft.com/en-us/windows/wsl/install-manual#downloading-distributions)，选最新的 `Ubuntu 24.04`
3. 两种安装策略：

   - 自动安装：可以直接运行下载后的文件自动安装，会自动安装到系统盘
   - 手动安装：将下载后的文件解压到自己喜欢的目录，如果是 appxbundle，其中还有 appx 需要继续解压，运行其中的 exe 文件即可，相当于安装在当前目录。安装完成后需要在 powershell 中执行 `wsl --update` 进行进一步安装。

     ![alt text](/assets/img/2025-03-12-wsl2-gpu-gui/image-2.png)

## 安装依赖

> 新版本的 windows 自带 WSLg，可以直接显示图形化程序，无需安装 x11 或 wayland 服务，可以直接执行 `xclock` 测试下

这里以<https://github.com/hkchengrex/Cutie/>这个项目为例：

1. 配置显卡环境

    - Nvidia 显卡

        只要主机安装了驱动就行，wsl 中无需额外操作

        ```shell
        nvidia-smi
        ```

        ![alt text](/assets/img/2025-03-12-wsl2-gpu-gui/image-3.png)

    - AMD 显卡

        1. 参考[本文](https://rocm.docs.amd.com/projects/radeon/en/latest/docs/install/wsl/install-radeon.html)进行驱动安装
        2. 参考[本文](https://rocm.docs.amd.com/projects/radeon/en/latest/docs/install/wsl/install-pytorch.html)进行 torch 安装

2. 安装 PyQt5 相关的依赖

    ```shell
    apt install python3-pyqt5
    apt install libxcb-cursor0
    export QT_QPA_PLATFORM=xcb
    ```

3. 配置 venv

    ```shell
    python3 -m venv venv
    source venv/bin/activate
    ```

4. 根据项目描述安装依赖并执行

    ```shell
    pip install -e .
    python cutie/utils/download_models.py
    python interactive_demo.py --video ./examples/example.mp4 --num_objects 1
    ```
